# Double Pendulum Simulator

## Overview

The Double Pendulum Simulator is a physics-based simulation developed using Python, Pygame, and NumPy. It models the motion of a double pendulum system consisting of two pendulums connected end-to-end.

Unlike a simple pendulum, a double pendulum exhibits chaotic behavior, meaning that very small changes in initial conditions can lead to completely different motion patterns. This makes it an excellent project for studying nonlinear dynamics and chaos theory.

## Features

* Real-time double pendulum simulation
* Chaotic motion visualization
* Motion trail tracking
* Physics-based calculations
* Smooth animation using Pygame

## How It Works

1. Two pendulums are connected together.
2. Gravity acts on both masses.
3. Angular accelerations are calculated using double pendulum equations.
4. Angular velocities and positions are updated every frame.
5. The resulting motion is displayed graphically.
6. The second mass leaves a trail showing its trajectory.
